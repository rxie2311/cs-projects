CS 2211: Software Tools & Systems Programming
-----------------------------------------------
In this directory are all of the projects I worked on during CS 2211.

Assignment 1 was not coded at all, so it is not included in this repository.
Assignment 2: Int to English - A converter that converts an integer to English text.
Assignment 3: Arrays - Rearranges and prints out user inputted arrays.
Assignment 4: Movie Theater Database - Creates a movie database that allows users to search, update and print out movies.
Assignment 5: Linked Lists - Modifies Assignment 4 to use a linked list for the database.

This directory also includes all labs that were done too. Labs are small assignments that were worked on in small, 
1 hour timeframes once a week.

These .c files are compiled using GAUL:
gcc (program name).c -o (program name without the .c)
To Run in GAUL: ./(program name without the .c)
