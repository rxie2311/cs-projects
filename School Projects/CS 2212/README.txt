CS 2212: Intro to Software Engineering
-----------------------------------------------
In this directory is the group project I worked on during CS 2212.

Group Project: Coding a Jeopardy game inside of Python using different design patterns and OOP.

OVERVIEW
-----------------------------------------------
All .py files are in the Code folder.
All assets (images) used for the game are in the Assets folder.
All text documents and excel sheets used to store data are in the Data folder.
All PyDoc comments used to explain the code are in the PyDoc Comments folder.
README contains instructions on how to play the game and execute the program.
