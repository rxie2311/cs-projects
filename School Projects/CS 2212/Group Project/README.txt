CS 2212 Final Project: Grid Genius - Group 22
-----------------------------------------------

DESCRIPTION
-----------------------------------------------
This software runs the game 'Grid Genius' on the user operating system.


REQUIRED TOOLS
-----------------------------------------------
The libraries and third party tools used are: pandas (2.2.1), pygame (2.5.2)


TOOLS INSTALLATION
-----------------------------------------------
Python Interpreter 3.9 is used, to check your version of Python:
python --version

pip should be installed, but if it is not:
python get-pip.py

To install pygame:
pip install pygame

To install pandas:
pip install pandas


INSTRUCTIONS - PLEASE READ
-----------------------------------------------
Once everything is installed, open and run "landingpage.py"

When starting the game, you will be prompted to create an account or login. After creating an account, you are required to log in.
Once logged in, you will have 6 buttons to choose from.
New game will create a gameboard that you can play. You choose tiles on the grid, answer questions, and accumulate points to try to complete the game.
Achievements shows you the unlockable achievements and your progress in each achievement.
Leaderboards displays the top 5 users with the highest score and top 5 users with most achievements completed.
Inventory allows you to customize your character in the game screen. Items are unlocked as you complete achievements.
The tutorial walks you through a game and teaches you game mechanics.
Admin mode will take you to a screen where you can view and edit user stats, delete an accout, or add a question to the question bank. This button is only accessible if logged in as admin.

Only a username and password is required to create an account and log in.

To gain admin powers, log in as admin with the following credentials:
Username: admin
Password: adminpass

To access teacher mode, log in as admin as specified above.
