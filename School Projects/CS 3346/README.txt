CS 3346: Introduction to Artificial Intelligence
-----------------------------------------------
In this directory is the group project I worked on during CS 3346.

Group Project: Training an AI agent using different RL algorithms (PPO, DQN, A2C) to play Atari Centipede.

OVERVIEW
-----------------------------------------------
Uses Arcade Learning Environment (ALE) to train the agent as well as access Atari Centipede.
All Jupyter Notebook files are in the Group Project folder.
Can be run in VSC or Google Colab.
