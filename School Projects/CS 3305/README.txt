CS 3305: Operating Systems
-----------------------------------------------
In this directory are all of the projects I worked on during CS 3305.

Assignment 1: Prime Number Counter - A program that uses child processes to count prime numbers in a range of numbers.
Assignment 2: Large Integer Multiplication Calculator - A program that takes two 4 digit ints, partitions them and uses pipes to calculate the product of the two.
Assignment 3: Sudoku Puzzle Verifier - A program that takes a 9x9 sudoku puzzle and uses threading to verify if it is correct.
Assignment 4: CPU Scheduling Algorithms - A program that simulates FCFS, SJF and Round Robin CPU scheduling algorithms.
Assignment 5: Bank Account Transactions - A program that uses mutex locks and threads to simulate bank account transactions.
