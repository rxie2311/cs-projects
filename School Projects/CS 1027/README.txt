CS 1027: Computer Science Fundamentals II
-----------------------------------------------
In this directory are all of the projects I worked on during CS 1027.

Assignment 1: Markov Chains - Checks for a Markov Chain in a matrix.
Assignment 2: Cribbage Counting - Checks for a Cribbage based on a hand of cards using Sets. 
Assignment 3: Dungeons and Dragons - Finds the shortest path through a dungeon map using Linked Lists.
Assignment 4: Files and Folders - Finds files and folders in a B Tree.

This directory also includes all labs that were done too. Labs are small assignments that were worked on in small, 
1 hour timeframes once a week.
