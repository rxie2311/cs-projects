CS 1026: Computer Science Fundamentals I
-----------------------------------------------
In this directory are all of the projects I worked on during CS 1026.

Assignment 1: Inflation Rate Calculator - Calculates inflation rate based on user input.
Assignment 2: Pizza Ordering System - Generates a pizza based on user input and prints a receipt. 
Assignment 3: University Ranking System - Gets a bunch of info about different universities in different cities.
Assignment 4: Air Travel System - Finds flights from different cities, using OOP.

This directory also includes all labs that were done too. Labs are small assignments that were worked on in small, 
1 hour timeframes once a week.
