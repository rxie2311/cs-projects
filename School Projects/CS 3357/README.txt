CS 3357: Computer Networks I
-----------------------------------------------
In this directory are all of the projects I worked on during CS 3357.

Assignment 1: HTTP Server - A TCP server that handles HTTP requests and responds to a client.
Assignment 2: TCP & UDP Chatroom - A TCP and UDP chatroom that allows clients to communicate via a server.
Assignment 3: Go-Back-N - A program that simulates the Go-Back-N protocol by dropping packets.
Assignment 4: Distance Vector - A program that uses Bellman-Ford Algorithm to calculate the shortest path to each node.
